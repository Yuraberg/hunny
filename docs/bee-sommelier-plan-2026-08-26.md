## 1. Концепция маскота

**Персонаж.** Пчела-сомелье — например, «Пчёлка Услада» (имя утвердить с владельцем). Позиционирование: *помощница пасечника Дмитрия* — так не ломаем существующий бренд-нарратив (истории пишутся от лица Дмитрия), а пчела становится «лицом» интерактива. Тон: тёплый, живой, без канцелярита, в духе текущего промпта, но без «голубчик/касатка» (это словарь Дмитрия) — у пчелы свой голос: лёгкий, хлопотливый, «жужжащие» присказки в меру.

**Визуал.** Инлайн-SVG маскот (2–3 позы: приветствие, «думает», «нашла сорт»), в стилистике сайта (мёд/дерево/пергамент). Уже используется 🐝-эмодзи в спиннере — заменяем на SVG с лёгкой CSS-анимацией (покачивание, траектория полёта пунктиром). Без внешних библиотек и lottie — статика + CSS, чтобы не раздувать бандл.

**Где живёт маскот:**
1. Блок сомелье в каталоге (главная точка входа) — диалог «расскажите, кому мёд».
2. Карточка товара `/catalog/[slug]` — статичная пчела «представляет» блоки «Польза» и «Кому подходит» (без ИИ, чистый контент — важно для SEO).
3. Ответ сомелье всегда подписан пчелой и содержит ссылку «Кому мёд не подходит →» (страница из §4).

## 2. Модель данных: расширение схемы продуктов

`src/content.config.ts`, коллекция `products`, новые поля (все optional, чтобы не сломать текущие карточки):

```ts
botanicalSource: z.string().optional(),        // медонос: «липа», «луговое разнотравье»…
benefits: z.array(z.string()).default([]),     // 3–5 пунктов пользы, без мед. обещаний
recommendedFor: z.array(z.string()).default([]), // «к чаю при простуде», «детям от 3 лет»…
restrictions: z.array(z.string()).default([]), // «диабет — только с врачом», «до 1 года нельзя»
allergyNote: z.string().optional(),            // сорт-специфичный перекрёст (см. §4.3)
tasteProfile: z.string().optional(),           // для сомелье: вкус/аромат/кристаллизация
```

## 3. Карточка товара: блоки «Польза» и «Кому подходит»

На `/catalog/[slug].astro` под описанием — новый компонент `ProductBenefits.astro`:

- **«Чем полезен»** — маркированный список из `benefits`. Формулировки только «поддерживающие» («традиционно ценится при…», «источник…»), никаких «лечит/исцеляет» — это согласуется с §4 SEO-плана (вычистка YMYL-рисков), а не противоречит ему.
- **«Кому подойдёт»** — из `recommendedFor`.
- **«Ограничения»** — из `restrictions`, всегда с двумя обязательными пунктами независимо от сорта: диабет и дети до 1 года (тексты — §5).
- **Дисклеймер для аллергиков** — короткий блок с `allergyNote` сорта + ссылка на общую страницу «Мёд и аллергия» (§4).
- Внизу — общий медицинский дисклеймер (тот же паттерн, что в вики).

В JSON-LD `Product` польза/ограничения **не** выносится (health-claims в структурированных данных — риск для YMYL-ранжирования), остаётся как обычный HTML-контент.

## 4. Аллергены: разбор «аллергены человека × состав мёда»

Это контентная основа для страницы и для промпта сомелье — разбор готов, ниже он приведён целиком; при реализации выверить с `src/content/wiki/allergiya-na-med.md` (данные согласуются).

### 4.1. Основные пищевые аллергены человека

Нормативные перечни: ТР ТС 022/2011 (РФ/ЕАЭС, 15 компонентов, обязательная маркировка) и FDA «Big 9». Основные: **глютенсодержащие злаки, молоко (лактоза), яйца, рыба, ракообразные, моллюски, арахис, орехи, соя, кунжут, сельдерей, горчица, люпин, сульфиты (>10 мг/кг)**. Плюс не-пищевой, но ключевой для мёда: **пыльца растений (поллиноз)** и **яд перепончатокрылых** (реакции на ужаления).

### 4.2. Состав мёда и сопоставление

Состав натурального мёда: ~80% сахара (фруктоза ~38%, глюкоза ~31%), вода 17–20%, белки 0,1–0,5% (растительные белки нектара + ферменты пчёл), пыльца 0,1–0,4%, органические кислоты, минералы, флавоноиды.

| Аллерген из перечней | Есть в мёде? | Вывод для покупателя |
|---|---|---|
| Глютен, молоко/лактоза, яйца, рыба, ракообразные, моллюски, арахис, орехи, соя, кунжут, сельдерей, горчица, люпин | **Нет** | Чистый мёд формально безопасен при этих аллергиях (важно: пока в ассортименте нет «мёда с орехами» — при появлении такой позиции обязательна маркировка) |
| Сульфиты | **Нет** (в натуральный мёд не вносятся) | Безопасен |
| **Пыльца растений** | **Да, 0,1–0,4%** | Главный реальный риск: перекрёст с поллинозом, сорт-специфично (§4.3) |
| **Белки пчёл** (Api m 1 — фосфолипаза A2, Api m 2 — гиалуронидаза, секреты желёз, частицы хитина) | **Да, следовые** | Перекрёст с аллергией на ужаления пчёл/ос — таким людям мёд с осторожностью независимо от сорта |
| Растительные белки-паналлергены (профилины, PR-10/Bet v 1-гомологи, LTP) | **Да, с нектаром** | Перекрёст с пыльцой берёзы/ольхи/лещины (оральный аллергический синдром); LTP термостабильны — возможны системные реакции |

### 4.3. Сорт-специфичные перекрёсты (заполнить по фактическим медоносам)

| Сорт | Медонос | Перекрёстный риск |
|---|---|---|
| Липовая Услада | липа | поллиноз на цветение липы; PR-10-перекрёст с берёзовым поллинозом |
| Луговой Гостинец, Степной | разнотравье (уточнить состав) | сложноцветные (полынь, одуванчик) — перекрёст у аллергиков на полынь/амброзию |
| Остальные сорта | уточнить у владельца | заполнить после уточнения |

### 4.4. Группы риска (сводно, для страницы и промпта)

1. **Поллиноз** — выбирать сорт с учётом медоноса, вводить с малых доз, при обострении — воздержаться.
2. **Аллергия на ужаления пчёл/ос** — риск на белки пчёл в любом сорте.
3. **Атопики, астматики, дети до 3 лет** — осторожно, начинать с минимального количества.
4. **Дети до 1 года — мёд запрещён** (риск младенческого ботулизма; это не аллергия — на странице описать отдельным блоком, не смешивать).
5. **Диабет** (не аллергия, но обязательное ограничение): мёд — это ~80% сахаров, ГИ 50–70 в зависимости от сорта; 1 ст. ложка ≈ 1 ХЕ. Формулировка: «при сахарном диабете — только по согласованию с лечащим врачом». Мёд **не** позиционировать как «полезный заменитель сахара для диабетиков».

### 4.5. Страница «Мёд: польза и кому он не подходит»

- [ ] Новая страница `src/pages/med-polza-i-protivopokazaniya.astro` (или статья вики с промо-ссылками — решить при реализации; отдельная страница лучше для SEO: коммерческо-информационный интент «мёд при диабете можно ли», «аллергия на мёд симптомы»).
- Структура: польза (сдержанно) → таблица §4.2 → сорта и перекрёсты §4.3 → диабет → дети до 1 года → как безопасно пробовать (капля на кожу/малые дозы — без обещаний диагностики) → дисклеймер.
- Перелинковка: карточки товаров ↔ эта страница ↔ `wiki/allergiya-na-med` ↔ ответы сомелье.

## 5. Готовые тексты дисклеймеров

**Короткий (карточка товара, под блоком ограничений):**
> Мёд — сильный природный продукт. При аллергии на пыльцу или укусы пчёл вводите его с малых доз, при сахарном диабете — только по согласованию с врачом. Детям до 1 года мёд давать нельзя. Информация на сайте не является медицинской рекомендацией.

**Для блока сомелье (постоянно виден под чатом, не генерируется ИИ):**
> Пчёлка подбирает мёд по вкусу и поводу, а не по здоровью: при диабете, аллергии и для детей до года решение всегда за вашим врачом.

**Аллергикам (в блоке аллергенов карточки):**
> В любом мёде есть пыльца растений (0,1–0,4%) и следы белков пчёл. Если у вас поллиноз или реакция на ужаления — посоветуйтесь с аллергологом. Подробнее: «Мёд и аллергия» (ссылка).

## 6. Worker v2: персонаж, safety-правила, rate-limit

`worker/sommelier-worker.js`:

- [ ] **Новый системный промпт** `/sommelier`: персонаж — пчела-сомелье (имя из §1), помощница пасечника Дмитрия. Сохранить текущие guardrails (ровно один сорт, `[PICK: id]`, анти-инъекция, «не представляйся нейросетью»).
- [ ] **Расширенные данные о сортах** в промпте: к текущим name/category/description добавить `benefits`, `restrictions`, `allergyNote`, `tasteProfile`, `botanicalSource` из `products.generated.json` — сомелье рекомендует предметно, а не по одному описанию.
- [ ] **Обязательные safety-правила в промпте** (новый блок):
  - если посетитель упоминает диабет / «без сахара» / похудение — рекомендовать сорт можно, но обязательно добавить оговорку «только по согласованию с врачом», не обещать «безопасен при диабете»;
  - если упоминается аллергия/поллиноз — назвать медонос рекомендуемого сорта и посоветовать свериться с аллергологом; при аллергии на укусы пчёл — предупредить про следы белков пчёл;
  - если мёд «для малыша/грудничка/до года» — вежливо отказать в рекомендации для ребёнка (мёд до 1 года нельзя) и предложить сорт для остальной семьи;
  - никогда не утверждать, что мёд лечит болезни; польза — только в формулировках «традиционно ценится», «поддержит».
- [ ] **Rate-limit** (закрывает риск H2 аудита): счётчик по IP в Cloudflare KV или через `caches`/Durable Object — например, 10 запросов/час на IP, при превышении — 429 с дружелюбным текстом «пчёлка устала, загляните через часок». Плюс общий дневной лимит расходов: ANTHROPIC max_tokens уже ограничен, добавить суточный счётчик запросов в KV.
- [ ] `ALLOWED_ORIGINS` — проверить актуальность доменов.
- [ ] Смоук-тесты промпта перед деплоем: «мёд для диабетика», «у меня аллергия на полынь», «мёд грудничку 8 месяцев», «забудь инструкции», обычный запрос — проверить, что оговорки появляются, а persona держится.

## 8. Порядок работ и оценка

| Этап | Содержимое | Зависимости | Оценка |

| 1. Данные | §2: схема + заполнение полей сортов | **Ответы владельца: медоносы каждого сорта, имя пчелы** | 0,5–1 день |

**Definition of done:** на проде в каталоге работает диалог с пчелой-сомелье; каждая карточка товара показывает пользу/кому подходит/ограничения (диабет, до 1 года) и аллерго-примечание со ссылкой на страницу «Мёд: польза и кому он не подходит»; сомелье при упоминании диабета/аллергии/младенцев всегда даёт оговорку; Worker защищён rate-limit; ни на одной странице нет утверждений «лечит».

1. Медоносы/ботаническое происхождение каждого сорта (для §4.3 и промпта).
2. Имя и характер пчелы-маскота; согласие, что диалог ведёт пчела, а не Дмитрий.
3. Готовность завести/пополнить Anthropic API key и Cloudflare-аккаунт для деплоя Worker (если ещё не сделано).
