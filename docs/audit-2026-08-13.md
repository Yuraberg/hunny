# Аудит кода Hanny (Медовая Слобода) — 13.08.2026

Один ревьюер (безопасность/логика) — проект маленький (~1560 строк: Astro + Node API + Cloudflare Worker + honey-wiki Python). Ничего не изменено.

---

## 🔴 HIGH

### H1. Клиентская цена доставки доверяется сервером
`api/server.js:90-94` — комментарий утверждает «цену доставки не доверяем», но `deliveryPrice` берётся из `req.body`. `deliveryPrice: 0` = бесплатная доставка без порога 10 000 ₽; для pickup — навязать любую цену. Сейчас ущерб 0 (тарифы Яндекса не подключены), но дыра готова.
**Фикс:** считать доставку на сервере (тариф × pointId/вес), pickup форсить 0, не принимать от клиента.

### H2. Worker с платным LLM без аутентификации (cost-abuse)
`worker/sommelier-worker.js:145-147` — `ALLOWED_ORIGINS` это CORS, не auth: `curl -H "Origin: https://medovayasloboda.ru"` проходит. Любой может жечь бюджет Anthropic через `/sommelier` и `/postcard`.
**Фикс:** Cloudflare Rate Limiting + Turnstile или секрет в заголовке + лимит/сутки на IP.

## 🟠 MEDIUM

- **Нет rate limiting на `/order` и `/payment/webhook`** — `server.js:50,152`: спам заказами + произвольные GET к api.yookassa.ru. Honeypot только на клиенте.
- **Express 4 не ловит reject в async-обработчиках** — висящие запросы при неожиданном исключении.
- **Вебхук ЮKassa: нет сверки суммы и metadata.orderId** — `server.js:152-172`: paymentId не валидируется как UUID. Defense-in-depth.
- **PII: privacy.html — незаполненный шаблон** при реальном сборе (имя, телефон, адрес в Postgres без ретеншена). 152-ФЗ.
- **Нет CSP/helmet, X-Powered-By раскрыт**.
- **Нет fail-fast проверки env** — без YOOKASSA_* сервер стартует с `Basic Og==`, заказы падают в 502 навсегда.
- **Нет верхнего предела qty** — `price*qty` переваливает MAX_SAFE_INTEGER, лимит ЮKassa 999 999,99 ₽ → 502.

## 🟡 LOW (выборка)
- `set:html` без экранирования `<` (JSON.stringify не экранирует `</script>`) — stored XSS при пользовательском контенте
- Markdown вики рендерит raw HTML без rehype-sanitize (статьи генерирует LLM)
- Дублирование шкалы скидок cart.ts vs pricing.js (при рассинхроне витрина ≠ сервер)
- Legacy index.html — мёртвый код с расходящейся логикой (не деплоится)
- Free-банки не фиксируются в items заказа
- `payment_id` без индекса (seq scan)
- Нет логирования запросов API

## ✅ Что чисто

- **Хардкод-секретов нет** — git-история (12 коммитов) чиста, всё через env/секреты (wrangler, GitHub Secrets)
- **Цены/скидки клиенту не доверяются** — сумма всегда пересчитывается на сервере по каталогу
- **ЮKassa-вебхук сделан правильно** — тело не подписано, статус перепроверяется собственным запросом к API. Подделка без реального платежа невозможна
- **SQL-инъекций нет** — параметризация, orderId UUID
- **XSS во фронте корзины закрыт** — escapeHtml, id фильтруются по каталогу
- **Prompt-injection в worker** — запрет инструкций из текста, вывод машиной из whitelist, вход 400 символов
- **honey-wiki** — path traversal закрыт, офлайн-генератор с фиксированными темами
- **Скидочный калькулятор** — шкала FE/BE идентична, freeUnits учтены, free shipping от дисконтированной суммы
